## Brand & Style

This design system establishes an atmospheric, focused, and high-performance digital environment tailored for an ambitious student developer portfolio. The design style combines **Dark Tonal Minimalism** with **Luminescent Tactility**—deep, organic forest greens meet high-contrast warm cream typography and targeted emerald luminescence. 

The emotional signature is composed, technically credible, and modern. Instead of cold, generic monochrome charcoal themes, the deep chlorophyll-infused dark foundation conveys depth, patience, and deliberate craftsmanship. Strategic neon-emerald accents highlight technical mastery, open-source metrics, and project vitality without sensory overwhelm.

### Design Principles
- **Atmospheric Grounding:** Canvas layers evolve from dense understory tones (`#0d2818`) to subtle container surfaces (`#163824`), keeping ambient distraction at absolute zero.
- **Luminescent Hierarchy:** Pure emerald light is strictly reserved for active states, interactive boundaries, achievements, and system feedback.
- **Editorial Contrast:** Body and display text deliberately avoid pure stark white in favor of warm, breathable creams and pale mint accents, ensuring sustained legibility across long code walk-throughs and project case studies.
- **Polished Precision:** Controlled inner boundaries, rounded container geometry, and monospaced technical metadata establish senior-grade UI rigor.

## Colors

The palette is engineered around high contrast on nocturnal forest backgrounds, maintaining AAA/AA accessibility compliance across all interactive and typographic states.

### Core Roles & Tokens
- **Canvas Base (`#0d2818`):** Deep primeval forest black-green; sets the stage for zero eye fatigue.
- **Surface Elevation 1 (`#133320`):** Base container fill for modules, cards, and sections.
- **Surface Elevation 2 (`#163824`):** Interactive card fill, elevated overlays, and active states.
- **Primary Accent (`#10b981`):** Core energetic emerald for primary CTAs, active pills, indicators, and focus rings.
- **Secondary Accent (`#059669`):** Deep emerald for interactive hover backgrounds and robust graphic anchors.
- **Tertiary Accent (`#34d399`):** Radiant mint used for glowing border highlights, focus effects, and graphical accents.
- **Text High-Emphasis (`#f4f7f4`):** Warm off-white cream providing maximum legibility without the harshness of pure white.
- **Text Medium-Emphasis (`#e8f0e9`):** Soft parchment-mint for secondary body copy, descriptions, and metadata.
- **Text Muted / Subtle (`#a7f3d0` at 65% opacity):** Pale mint for labels, captions, and secondary icons.
- **Border Default:** `rgba(52, 211, 153, 0.12)` for subtle perimeter definition.
- **Border Glow / Highlight:** `rgba(52, 211, 153, 0.45)` with ambient falloff for active, focused, or featured states.

## Typography

The typography pairings intentionally balance clean contemporary geometric sans-serif shapes (`Plus Jakarta Sans`) with disciplined, developer-native monospaced type (`JetBrains Mono`).

### Hierarchy & Composition Rules
- **Display & Headlines:** Set tight negative tracking on `display-hero` through `headline-md` to reinforce confident editorial punch. These headings use `#f4f7f4`.
- **Body & Longform:** Standardize long-form reading on `body-md` and `body-lg` using `#e8f0e9` for balanced, eye-friendly contrast against `#0d2818` backdrops.
- **Code & Technical Accents:** All tech stacks, timestamps, git commits, terminal readouts, and badge metrics must be typeset in `JetBrains Mono` to reinforce developer credibility and structural discipline.
- **Responsive Adaptations:** Titles larger than `32px` automatically step down on mobile screens to preserve line wrap balance and vertical composition.

## Layout & Spacing

The layout system is built on a responsive 12-column fluid grid, locked to a max-width container of `1280px` for optimal reading scan lines and showcase presentation.

### Grid Model
- **Desktop (1024px+):** 12 columns, `1.5rem` (`24px`) gutters, `3rem` (`48px`) margins. Generous padding creates a gallery-grade canvas that lets project cards breathe.
- **Tablet (768px – 1023px):** 8 columns, `1.25rem` (`20px`) gutters, `2rem` (`32px`) margins. Two-column card splits convert gracefully.
- **Mobile (< 768px):** 4 columns, `1rem` (`16px`) gutters, `1.25rem` (`20px`) margins. Stacks cards to single-column order with tight layout flow.

### Spacing Philosophy
Consistent `8px` modular spacing coordinates internal element relationships. Component interior padding transitions uniformly from `space-md` on compact mobile cards to `space-xl` on hero modules and featured project exhibits. Vertical flow relies on intentional whitespace gaps rather than hard dividing rules.

## Elevation & Depth

Visual hierarchy uses **Tonal Layering** accompanied by **Subtle Ambient Emerald Luminescence**. In place of heavy, dirty black drop-shadows, depth is expressed through translucent boundary lines and targeted colored glow.

### Elevation Hierarchy
- **Canvas (Level 0):** `#0d2818` – Global background plane.
- **Resting Container (Level 1):** `#133320` – Bordered with `1px solid rgba(52, 211, 153, 0.12)`. No drop-shadow needed; contrast is achieved by surface tone step-up.
- **Elevated / Interactive Surface (Level 2):** `#163824` – Applied to cards on hover, tooltips, and floating navigation bars. Outlined by `1px solid rgba(52, 211, 153, 0.35)`. Enhanced with an ambient emerald glow: `box-shadow: 0 12px 32px -8px rgba(16, 185, 129, 0.18), 0 0 0 1px rgba(52, 211, 153, 0.25)`.
- **High-Impact Accent (Level 3):** Modal overlays, primary active action targets, and featured milestone cards. Bordered by `1.5px solid rgba(52, 211, 153, 0.6)` with dual glow: `box-shadow: 0 0 24px 0 rgba(16, 185, 129, 0.25), 0 20px 40px -10px rgba(5, 150, 105, 0.3)`.

## Shapes

The design uses a refined, rounded geometric profile matching modern product design interfaces.

- **Base Components (`rounded-md` / `0.5rem`):** Buttons, code snippets, inputs, and tab triggers.
- **Cards & Visual Containers (`rounded-2xl` / `1rem` to `1.5rem`):** Project showcase cards, modal dialogs, and code preview containers carry generous `rounded-2xl` rounding to match the user's signature aesthetic request.
- **Pills (`rounded-full`):** Category tags, technology badges, status indicators, and floating back-to-top controls.

## Components

### Buttons
- **Primary:** Solid `#10b981` background, `#0d2818` bold typography, `rounded-md`, horizontal padding `1.25rem`, vertical padding `0.75rem`. Hover state transitions to `#34d399` with an outer emerald diffusion `box-shadow: 0 0 16px rgba(16, 185, 129, 0.4)`.
- **Secondary (Ghost Outline):** Transparent fill, `1px solid rgba(52, 211, 153, 0.3)` border, `#f4f7f4` text. On hover: background shifts to `rgba(22, 56, 36, 0.7)` with full border glow at `rgba(52, 211, 153, 0.6)`.
- **Icon / Code Action:** Subtle square or circle button with `#163824` fill, `#a7f3d0` icon fill, transitioning to crisp emerald illumination when triggered.

### Cards (Project & Experience)
- Constructed with `#133320` base, `rounded-2xl` border radius, and internal padding of `1.75rem` to `2rem`.
- Perimeter framed with subtle `1px solid rgba(52, 211, 153, 0.14)`.
- **Hover Interaction:** Card translates vertically `-4px`, border brightens to `rgba(52, 211, 153, 0.45)`, and the outer emerald ambient bloom (`0 16px 36px -10px rgba(16, 185, 129, 0.2)`) activates smoothly over 250ms.

### Chips & Badges
- **Tech Stack Badges:** JetBrains Mono `label-code-sm`, background `#163824`, border `1px solid rgba(52, 211, 153, 0.2)`, text `#a7f3d0`. Pill-shaped geometry.
- **Live Status Chip:** Pill container with an emerald-pulsing dot (`#10b981`), `#133320` container fill, and text `#f4f7f4`.

### Input Fields & Terminal Search
- Background `#0d2818` with subtle border `1px solid rgba(52, 211, 153, 0.2)`.
- Typography set to JetBrains Mono `#f4f7f4` with placeholder tinted to `#a7f3d0` at 40% opacity.
- **Focus State:** Border shifts cleanly to `#10b981` accompanied by an emerald focus ring: `0 0 0 3px rgba(16, 185, 129, 0.25)`.

### Code Blocks & Interactive Demos
- Terminal wrapper featuring `#133320` background, window controls (subtle tinted emerald/mint dots instead of rainbow traffic lights), syntax highlighting keyed to warm cream, pale mint, and high-visibility emerald.
- Bordered in `1px solid rgba(52, 211, 153, 0.18)` with `rounded-xl` corners.

### Lists & Activity Feeds
- Milestone timeline using thin vertical guides in `rgba(52, 211, 153, 0.2)`.
- Timeline nodes rendered as small emerald discs with optional ping animation for in-progress student research or active hackathons.
